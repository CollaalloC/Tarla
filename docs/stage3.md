# 阶段三 · 客户端、网关与单终端接管

主管、执行机、App 和 IM 都使用工作空间内的同一会话编号。手机或网关退出后，任务仍由执行机上的私有 Herdr 持有。客户端首页提供对话、进行中的任务、等我处理和记忆四个入口。

后台部署与数据恢复见[阶段二指南](stage2.md)，自动生成经验的配置与限制见[任务经验提纯](run-distillation.md)。

## 手机连接与终端

1. 为主管配置受手机系统信任的 HTTPS 地址，在反向代理上启用 WebSocket Upgrade。打开 App，选择“连接工作空间”，输入工作空间 ID、主管地址和该工作空间的客户端令牌。Android 模拟器的开发地址可使用 `http://10.0.2.2:7878`，iOS 模拟器可使用 `http://127.0.0.1:7878`。
2. 在对话中提交任务，打开“进行中的任务”查看详情。只读模式用于观察终端。接受键盘输入的执行程序可以选择交互接管。按轮次输入的原生工位会显示继续会话的方式。
3. 双机情况下，若执行机有手机可达的受信任 HTTPS 入口，可在主管配置的对应 `[[peers]]` 中设置 `client_url = "https://worker.example.com"`。通过 CLI 新建配对时也可加 `--client-url https://worker.example.com`。原有 `url` 继续用于节点间配对与同步。客户端优先通过手机可达的端点直连，执行节点自行签发并验收单终端票据。
4. 如果执行机只在主管的私有组网内可达，在线主管可以转发该次终端连接。转发仅使用任务账本登记的执行节点和终端。握手后数据沿主管到执行机的既有配对网络传输。主管下线时，已配置备用执行机地址和独立令牌的客户端可直接查看执行现场；这要求手机本身能够访问该地址。

票据绑定工作空间、执行机、任务、终端和读写模式，有效握手时间为 60 秒，单次使用。终端连接断开后需重新签发。手机无需接触 Herdr 的宿主 Socket。

## IM 与审批

按[网关配置与配对](../crates/tarla-gateway/README.md)启用 Telegram 或飞书，给目标用户生成一次性配对码。同一逻辑会话可从多个入口继续。在“等我处理”中操作前，可先核对任务、发起节点和申请内容。需要在终端中回答的提示会引导用户打开对应任务现场。
