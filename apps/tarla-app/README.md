# Tarla 客户端

同一套 Flutter 客户端连接工作空间的 `tarlad`，可在 iOS、Android、macOS、Windows 与 Linux 上运行。项目使用 Flutter 3.38 的原生平台工程。构建 iOS / macOS 需要装有 Xcode 的 Mac，构建 Windows 需要安装 Visual Studio C++ 工具链的 Windows。

```sh
flutter pub get
flutter analyze
flutter test
flutter devices
flutter run -d <device-id>
```

Android 模拟器使用 `http://10.0.2.2:7878` 连接宿主上的开发服务。iOS 模拟器和桌面端使用 `http://127.0.0.1:7878`。远端节点使用受系统信任的 HTTPS 服务地址，终端代理需支持 WebSocket Upgrade。Android 发布安装包需配置自己的发布签名。

启动后点击“连接工作空间”，输入工作空间名称、主管服务地址和该空间的访问令牌。顶部菜单可以添加另一工作空间或切换。连接配置和令牌在本次应用进程内使用。要在主管断网后访问现场，可为该工作空间设置一个已配对执行节点的地址和独立令牌。备用连接仅在主管连接失败时启用，身份校验失败会直接显示错误。

- **对话**支持创建和接续会话，右上角的频道路由可将已有会话固定至执行工位，或恢复主管模式。
- **进行中**展示执行状态、执行节点和结果。在已关联持久终端的任务详情里，可以申请只读旁观或交互接管。客户端只把任务票据交给目标节点。
- **等我处理**展示审批、记忆冲突和工位登录状态。处理冲突时会提交界面所展示的版本号。
- **记忆**展示当前空间的长期记忆、版本、同步游标和机器环境。修订请求携带原版本号。
