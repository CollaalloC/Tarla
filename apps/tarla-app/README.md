# Tarla 客户端

同一套 Flutter 客户端连接工作空间的 `tarlad`，可在 iOS、Android、macOS、Windows 与 Linux 上运行。项目使用 Flutter 3.38 的原生平台工程。构建 iOS / macOS 需要装有 Xcode 的 Mac，构建 Windows 需要安装 Visual Studio C++ 工具链的 Windows。

```sh
flutter pub get
flutter analyze
flutter test
flutter devices
flutter run -d <device-id>
```

Android 模拟器使用 `http://10.0.2.2:7878` 连接宿主上的开发服务。iOS 模拟器和桌面端使用 `http://127.0.0.1:7878`。远端节点使用受系统信任的 HTTPS 服务地址，终端代理需支持 WebSocket Upgrade。Android 发布安装包需配置自己的发布签名。

启动后点击“连接工作空间”，输入服务端配置的工作空间 ID、主管服务地址和该空间的访问令牌。顶部菜单可以添加、切换、编辑或移除工作空间的本机配对。Android 使用 Android Keystore 中的 AES-GCM 密钥加密地址、令牌及当前空间，密文存储在应用的免备份目录。iOS 使用仅在本设备解锁时可读取的 Keychain 项。移动端重启后恢复上次选择的工作空间。桌面端的手工连接仅保存在本次会话。要在主管断网后访问现场，可为该工作空间设置一个已配对执行节点的地址和独立令牌。备用连接仅在主管连接失败时启用。客户端先核对服务端的工作空间 ID，再发送访问令牌。工作空间或身份校验失败时会直接显示错误。

- **对话**支持创建和接续会话，右上角的频道路由可将已有会话固定至执行工位，或恢复主管模式。
- **进行中**展示任务目标和执行状态。打开详情可查看执行节点、回执与分页日志。在已关联持久终端的任务详情里，可以申请只读旁观或交互接管。主管可返回执行节点的受信 HTTPS 地址或本站终端中转。直连握手遇到网络故障时，客户端会向主管申请新的中转票据；主管离线时可向已配对执行机申请票据。WebSocket 握手只携带当前任务的短期票据。任务只支持旁观时，详情页会展示可用的输入方式。
- **等我处理**展示审批、记忆冲突和工位登录状态。处理冲突时会提交界面所展示的版本号。
- **记忆**展示当前空间的长期记忆、版本、同步游标和机器环境。修订请求携带原版本号。
